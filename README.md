# 🌸 SAP REFERENTIAL

Référentiel technique orienté **SAP GUI et développement ABAP classique**. Le parcours est conçu pour permettre à un débutant de comprendre une notion, l’appliquer, vérifier le résultat et disposer d’un squelette réutilisable.

## 🌺 Principes du référentiel

- Définitions explicites des termes SAP et ABAP.
- Procédures reproductibles dans un système de développement.
- Cas d’usage professionnels.
- Exemples et snippets à adapter.
- Diagrammes Mermaid compatibles GitHub.
- Références vers la documentation officielle SAP.
- Séparation stricte entre les procédures SAP GUI et les futurs contenus ADT/Eclipse.
