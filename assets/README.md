# 🌸 RESSOURCES VISUELLES

Ce dossier est réservé aux illustrations originales ou aux captures dont la diffusion est autorisée.

Les écrans et images provenant de SAP Help Portal ou SAP Learning ne sont pas recopiés automatiquement : leur présence sur un site officiel ne les place pas sous la licence du présent repository. Les chapitres utilisent des diagrammes Mermaid originaux et des liens vers les procédures officielles SAP.

Pour ajouter une capture SAP GUI :

1. utiliser un système de démonstration ou un environnement autorisé ;
2. masquer utilisateurs, SID, mandants, noms de clients et données métier ;
3. enregistrer l’image au format PNG ou WebP ;
4. documenter la source et le droit de diffusion ;
5. ajouter un texte alternatif descriptif dans le Markdown.
